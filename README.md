# PromptPilot
Pick a marketing goal, fill in a few fields, and get a clear, structured prompt you can paste into any AI tool. A strength meter shows what your prompt is still missing, and a library keeps your best prompts for reuse.

PromptPilot does not call any AI service. It only builds prompts, and everything is saved in your browser.

## Add your own template
Open `src/App.jsx` and add an item to `TEMPLATES` with a name, role, goal, fields and output.

## Run
`npm install` then `npm run dev`. Build with `npm run build`. Deploy to Vercel or run `npm run deploy` for GitHub Pages.
